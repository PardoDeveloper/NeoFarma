# ADR 0003 — Sesiones de caja

**Estado:** aceptado · 2026-09-25

- Cada venta pertenece a una sesión de caja abierta del usuario. Índices únicos parciales garantizan **una sesión abierta por caja y por usuario**.
- Efectivo esperado = fondo inicial + ventas en efectivo + ingresos − egresos. Al cerrar se registra el efectivo contado y la diferencia.
- La venta toma `FOR SHARE` sobre la sesión y el cierre `FOR UPDATE`: no se puede cerrar una caja mientras se registra una venta.
- Solo se anulan ventas de sesiones abiertas, para no alterar cierres ya cuadrados. Anular requiere rol químico/admin.
